## 这不是你的问题，是工具的割裂

![色彩缠绕的杂乱线缆](https://image-search-mcp-cn-beijing.oss-cn-beijing.aliyuncs.com/image-search-mcp/images-ppt/d2bbb7e548be.jpg)
{: custom-slidev-layout="image-left" }

- **内容割裂**：笔记一份、幻灯片一份，人人都是搬运工
- **正文污染**：配置代码混进 Markdown，笔记不再纯净
- **门槛高筑**：酷炫动效背后，是 Node 与命令行的高墙
- **表现贫瘠**：代码错乱、列表平铺，听众悄然走神

> [!NOTE] 💡 演讲备注
> 安抚听众：这不是你不够努力，而是工具天生割裂。
> 逐条点出四宗罪：内容两份、正文污染、环境门槛、表现力不足。
> 结论：问题不在人，在工具。
{: custom-slidev-note="true"}

## 核心理念：正文零污染

![清澈透底的碧蓝湖水](https://image-search-mcp-cn-beijing.oss-cn-beijing.aliyuncs.com/image-search-mcp/images-ppt/2983a3766ac0.jpg)
{: custom-slidev-layout="image-left" }

所有演示配置，都沉淀在思源块属性之中。

- 版式、转场、动画：写入块属性，正文不增一行代码
- 演讲提词：收进私有备注，不扰阅读
- 导出 Markdown 依旧 100% 纯净
- 移动端阅读、标准导出，零乱码

> [!NOTE] 💡 演讲备注
> 强调第一条设计原则：正文零污染。
> 配置全部进块属性，提词进私有备注；Markdown 一字不改，导出纯净、移动端零乱码。
{: custom-slidev-note="true"}
