## 一、系统概述与设计原则

在放映 Slidev 演示幻灯片（无论是内置 Web 沙箱引擎还是 Slidev Pro CLI 引擎）时，演讲者常常需要点击幻灯片中的**网页链接**或**思源笔记双链/块引用**。传统跳转会导致窗口切出或思源主工作区标签页切换，严重打乱现场放映节奏。

本方案构建了一套与全屏放映同级绑定的**原位沉浸式扩展层（In-situ Immersion Overlay System）**，实现：
1. **原位呼出与同级渲染**：无需切换应用或工作区，抽屉浮层在幻灯片上方直接滑出；
2. **上下文零丢失**：当前幻灯片页码、`v-click` 动画步骤、计时状态完全保留原样；
3. **双模双轨支持**：
   - **思源笔记轨**：拉起原生 `Protyle` 实例，默认只读防误触，支持一键切换即时勘误，并具备文档历史栈回退；
   - **Web 网页轨**：拉起 Electron `<webview>` 微型浏览器，支持 70% 对照/100% 满屏切换、缩放步进与全套受控导航；
4. **全屏防打扰与事件栈治理**：多层 `ESC` 响应栈，抽屉激活时冻结幻灯片键盘翻页，保证现场零失误。

## 三、详细功能模块设计

### 1. 全屏与浮层容器架构 (`ImmersionDrawerContainer`)

#### 1.1 容器挂载与全屏提升
- **挂载点改造**：改造 `SlidevPreviewTab.vue`，将内部视口区域包裹进顶层容器 `.spm-slidev-fullscreen-container`。
- **全屏事件重构**：
  - 点击全屏按钮或按 `F` 快捷键时，对 `.spm-slidev-fullscreen-container` 触发 `requestFullscreen()`；
  - 监听 `fullscreenchange` 事件，自动同步 `isFullscreen` 状态；
  - 沙箱 `iframe` 与 `ImmersionDrawerContainer` 处于同一全屏层级，确保抽屉打开时绝对不会被系统全屏图层遮盖。

#### 1.2 视口模式与尺寸变换
- **70% 宽对照抽屉（默认形态）**：
  - 占屏幕宽度 65% ~ 75%（右侧滑出），左侧透出当前 Slide 页面；
  - 适用场景：演示时对照网页文档、API 规范或佐证材料。
- **100% 满屏最大化形态**：
  - 点击顶栏 `🗖 最大化` 按钮，抽屉平滑扩展至 100% 视口宽；
  - 适用场景：全屏现场演示在线 Web 系统、Live Demo 操作或大型思源多维表格。
- **暗色遮罩与平滑过渡**：
  - 背景渲染 `rgba(0, 0, 0, 0.45)` 遮罩层；
  - 点击遮罩或右上角 `✕` 触发 `slide-right` 退出动效。

---

### 2. 链接拦截与双轨 IPC 通信管道

#### 2.1 拦截目标与匹配模式
系统拦截两类目标元素：
1. **思源内部链接 / 块引用**：
   - 协议链接：`siyuan://blocks/{blockId}`
   - 块引用标签：`<div class="slidev-block-ref" data-ref-id="{id}">`、`<span class="slidev-ref-tag" data-ref-id="{id}">`
   - 包含思源块 ID 特征的锚文本与内联链接
2. **Web 外部网络链接**：
   - 以 `http://` 或 `https://` 开头的超链接 `a[href]`

#### 2.2 双引擎统一拦截机制
1. **内置 Web 沙箱引擎 (`slidev-client/index.html`)**：
   - 注册全局捕获阶段点击监听：
     ```ts
     document.addEventListener('click', (e) => {
       const refEl = e.target.closest('[data-ref-id]')
       const linkEl = e.target.closest('a')
       if (refEl) {
         e.preventDefault()
         e.stopPropagation()
         postToHost('OPEN_PEEK_DRAWER', { type: 'siyuan', blockId: refEl.getAttribute('data-ref-id') })
         return
       }
       if (linkEl && linkEl.href) {
         const href = linkEl.getAttribute('href') || ''
         if (href.startsWith('siyuan://blocks/')) {
           e.preventDefault()
           e.stopPropagation()
           const blockId = href.replace('siyuan://blocks/', '').split('?')[0]
           postToHost('OPEN_PEEK_DRAWER', { type: 'siyuan', blockId })
         } else if (/^https?:\/\//i.test(href)) {
           e.preventDefault()
           e.stopPropagation()
           postToHost('OPEN_PEEK_DRAWER', { type: 'web', url: href, title: linkEl.innerText })
         }
       }
     }, true)
     ```
2. **Slidev Pro CLI 引擎 (`localhost:3030`)**：
   - 通过 `workspace-scaffolder.ts` 在临时工程中自动注入 `setup/root.ts` 钩子脚本；
   - 监听同构的 `click` 事件并向 `window.parent.postMessage` 上报 `OPEN_PEEK_DRAWER`，保障双轨引擎行为 100% 一致。

---

### 3. 思源内部文档轨：Protyle 原位速览抽屉 (`ProtylePeekDrawer.vue`)

#### 3.1 实例挂载与参数配置
- 在抽屉挂载容器内调用官方 API 初始化 Protyle：
  ```ts
  const protyle = new Protyle(plugin.app, containerEl, {
    blockId: targetBlockId,
    action: ['cb-get-hl', 'cb-get-context'],
    render: {
      background: true,
      title: true,
      gutter: true,
      breadcrumbDocName: true
    }
  })
  ```
- **全特性支持**：100% 完整支持原生 Markdown 块高亮、数学公式、代码块、Mermaid、以及多维表格属性视图（Database / AV）。

#### 3.2 只读速览与即时编辑切换
- **默认模式**：初始化完成后立即调用 `protyle.disable()` 进入**只读速览模式**，防止演示过程中鼠标误触改动正文；
- **解锁编辑**：抽屉顶栏提供 `✏️ 即时编辑` 按钮：
  - 点击后调用 `protyle.enable()` 并聚焦，解除输入禁用；
  - 演讲者可现场勘误文字、在属性表格中修改字段数据；
  - 再次点击可切回只读锁定态。

#### 3.3 深度嵌套双链的栈式历史回退
- 演讲者在 Protyle 中可能继续点击内部的其他引用链接；
- 建立 `historyStack: Array<{ blockId: string, title?: string }>` 导航栈；
- 当在抽屉内触发深层跳转时，将旧节点 push 进历史栈，Protyle 实例就地重载；
- 顶栏显示 `← 返回上层文档` 按钮与面包屑路径，支持平滑回退，避免演示迷航。

#### 3.4 独立置顶小窗口联动
- 抽屉顶栏右侧提供 `🗗 置顶独立窗口打开` 动作：
  - 调用思源 API `openWindow({ doc: { id: currentBlockId }, alwaysOnTop: true })`；
  - 适合需要打开思源全局 Dock、完整侧边栏与重度外部插件的深度编辑场景；
  - 独立窗口关闭后焦点自动还给演示界面。

---

### 4. Web 外部链接轨：微型浏览器抽屉 (`WebviewPeekDrawer.vue`)

#### 4.1 Electron 原生 `<webview>` 嵌入
- 桌面端环境利用思源已开启的 `webviewTag: true` 能力，直接动态挂载 `<webview>` 标签；
- 独立隔离的 Chromium 渲染沙箱，天然穿透并免疫 `X-Frame-Options: SAMEORIGIN/DENY` 与页面 CSP 限制；
- 完整保留网站 Cookie 与登录态。

#### 4.2 受控演讲导航栏与新窗口拦截
- **导航控制条**：
  - `[←]` 后退、`[→]` 前进、`[🔄]` 刷新页面；
  - 网址输入/只读显示栏；
  - `[📋]` 复制当前 URL；
  - `[↗]` 在系统默认浏览器中打开。
- **新窗口拦截 (Target="_blank")**：
  - 监听 `<webview>` 的 `new-window` 事件；
  - 阻止弹出外部窗口，改由当前 webview 实例调用 `loadURL(e.url)` 就地重定向，防止外部浏览器抢焦点导致演示中断。

#### 4.3 显式缩放控制 (Zoom Factor)
- **顶栏控件**：`[➖] 100% [➕]`；
- **步进缩放**：每次点击调整 `±10%`（范围 50% ~ 200%）；
- 调用底层 `webview.setZoomFactor(currentFactor)`；
- 同时监听组合键 `Ctrl/Cmd + 滚轮` 与 `Ctrl/Cmd + +/-/0` 快捷键。

#### 4.4 Web/Docker 端优雅降级保障
- 检测到当前宿主为浏览器 Web 端（无 `<webview>` 支持）时：
  - 尝试以降级 `<iframe>` 载入；
  - 若检测到加载错误或 CSP 阻断，呈现友好占位提示卡片，并提供大按钮「在外部浏览器新标签页打开 ↗」。

### 5. 键盘事件治理与生命周期销毁

#### 5.1 双层 ESC 响应栈
```
[按下 ESC 键]
  │
  ├──► 当前抽屉处于打开状态？
  │      ├─ 是 ──► 调用 closeDrawer() 收起抽屉，阻止冒泡，保持全屏放映
  │      └─ 否 ──► 触发默认全屏退出（exitFullscreen）
```

#### 5.2 翻页热键阻断与解冻
- **抽屉打开时**：
  - 抽屉根节点拦截 `keydown` 事件并调用 `e.stopPropagation()`，防止 `Space`、`ArrowLeft`、`ArrowRight`、`PageUp`、`PageDown` 穿透触发 Slidev 翻页；
  - 向沙箱下发 IPC 指令：`{ action: 'FREEZE_KEYBOARD_NAV', payload: { frozen: true } }`。
- **抽屉关闭时**：
  - 向沙箱下发解冻指令：`{ action: 'FREEZE_KEYBOARD_NAV', payload: { frozen: false } }`。

#### 5.3 内存释放与销毁管线
- 抽屉关闭动画结束（或卸载）时：
  - **Protyle**：显式执行 `protyleInstance.destroy()`，清空 DOM 容器，避免挂载泄露；
  - **Webview**：将 `<webview>` 节点从 DOM 树完全移除，终止页面音频与后台脚本执行；
  - 清理历史导航栈与定时器。

## 五、关键代码规范与边界防御

1. **DOM 隔离与层级管理**：
   - 抽屉容器必须设置显式 `z-index: 1000`，且严格限制在 `.spm-slidev-fullscreen-container` 内部，避免污染主界面 Dock 或对话框。
2. **异步清理（Leak-free Cleanup）**：
   - 在 Vue `onBeforeUnmount` 与抽屉关闭回调中，必须同步执行 `protyle.destroy()` 并解绑全局事件监听。
3. **安全规范**：
   - `<webview>` 标签严格禁止开启 `nodeintegration`，必须保持 Chromium 独立隔离沙箱运行，防范恶意外链脚本注入。
