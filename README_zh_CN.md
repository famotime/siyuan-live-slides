# 思源笔记即现演示插件 (SiYuan Live Slides)

[📖 详细使用指南](./docs/USER-GUIDE.zh-CN.md) | [📖 User Guide (EN)](./docs/USER-GUIDE.md) | [📦 更新日志 (Changelog)](./CHANGELOG.md)

> **“让笔记即是演示，让演讲回归内容；开箱即用的现代演示体验。”**
>
> 专为 [思源笔记 (SiYuan Note)](https://b3log.org/siyuan/) 打造的一体化现代演示插件。它将现代组件化演示框架的灵动视觉深度引入思源生态，彻底告别传统“排版耗时、复制搬运繁琐、正文代码污染、演讲容易忘词”的痛点，让每一篇笔记都能在数秒内蜕变为专业级演示文稿。

---

## 🌟 为什么选择「即现」？

制作演示文稿往往伴随着令人抓狂的割裂与繁琐。「即现」从根本上重新定义了笔记与演示的关系：

| 痛点场景 | 传统演示方案（PowerPoint / 传统 Markdown 插件） | 「即现」带来的革命性体验 |
| :--- | :--- | :--- |
| **笔记与 PPT 严重割裂** | 每次汇报都要从笔记复制粘贴到 PPT 里机械排版几小时；笔记一旦修改，PPT 立即沦为过时孤岛。 | **文档即演示**：直接在思源笔记中开启演示，内容天然同源；笔记修改后演示画面毫秒级自动同步。 |
| **正文被宏代码严重污染** | 传统插件必须在正文插入大量 `<!-- .slide: class="xxx" -->` 等特殊注释，让原笔记面目全非。 | **正文绝对零污染**：所有版式、动画、转场、演讲备注均保存在思源块属性中，导出的 Markdown 依然纯净如初。 |
| **复杂的环境与配置门槛** | 现代代码型演示工具往往需要安装 Node.js、npm 依赖并手动启动本地服务，普通用户望而却步。 | **0 依赖开箱即用**：纯内置轻量 Web 沙箱，思源集市下载启用即生效，无需配置任何外部开发环境。 |
| **排版单调缺乏表现力** | 传统幻灯片只能机械罗列文字，缺乏动效引导，观众容易注意力涣散或提前扫完全部内容。 | **现代动效与版式**：支持 `v-click` 逐步弹出、微动效入场、代码逐行聚光、动态蒙版分步展露等灵动视觉。 |
| **放映中操作 Demo 易切屏** | 讲到系统演示或在线网页时只能跳出全屏切换浏览器，容易暴露桌面隐私且破坏演讲沉浸感。 | **沉浸速览抽屉**：放映中点击外链或 Demo 原位滑出微型浏览器与交互抽屉，测试完一键收起，观众全程不出戏。 |
| **演讲现场紧张容易忘词** | 缺乏演讲者视角，不知道下一页是什么，看着投影仪念稿容易卡壳、超时。 | **专业双屏演讲者视图**：外接大屏纯净放映，主屏实时呈现计时器、大字号提词卡与下一页半透明剧透预览。 |

## 🎯 核心特性与用户价值

### 一、文档即演示，免搬运、零污染

#### 1. 0 依赖、免装 Node/CLI，开箱即用
无需安装 Node.js、无需配置 npm 环境、无需在终端敲击任何命令行指令。只需在思源笔记集市中下载并启用「即现」插件，完整的演示引擎即刻就绪，无论是轻薄办公本还是移动环境，演示功能毫秒级即开即用。

#### 2. 无需重复搬运，一条 `---` 即可分页开启放映
不再需要在 PPT 软件和思源笔记之间来回复制粘贴。在笔记中只需通过输入原生的 `---` 水平分割线做好内容分页，在可视化面板中简单点选页面版式与组件动画效果后，即可一键进入“PPT”放映状态，轻松实现“记完即讲”。

#### 3. 内容与演示实时联动，双向毫秒级同步
- **光标智能跟随**：在上方笔记编辑器中移动光标，下方演示分屏自动毫秒级翻到对应幻灯片并聚焦高亮当前段落。
- **反向精准定位**：在演示画面中点击任意文字、列表或图片，笔记编辑器即刻平滑滚动对齐到对应的源笔记块。
- **会议边讲边改**：现场汇报收到修改建议？随手在笔记中补充修订，下方演示画面即时热更新；通过 📌 **Pin 锁定** 功能，还能在查阅其他参考文档时保持放映画面纹丝不动。

#### 4. 所有配置保存在思源块属性中，正文绝对零污染
版式、动画、转场、演讲备注等所有演示元数据，全部保存在思源原生的 IAL 自定义块属性字典中。正文 Markdown 不包含任何杂乱的特殊宏语法或注释代码，在移动端阅读、全局检索、双链引用以及导出为标准 Markdown 时，文档始终保持 100% 纯净整洁。

### 二、友好设置界面，快速呈现不一样的“PPT”

#### 1. 丰富实用的页面排版与丝滑页面转场
右侧可视化检查器面板提供直观的九宫格点选，无需记忆任何排版语法：
- **经典与现代版式**：涵盖封面 (`cover`)、标准正文 (`default`)、双栏对比 (`two-cols`)、自适应 2~6 栏的表头多栏 (`cols-header`)、四象限田字矩阵 (`clover`)、图左/图右 (`image-left`/`image-right`)、核心结论大字报 (`fact`)、章节过渡 (`intro`) 等多种专业版式。
- **自定义分栏比例**：自由设定双栏与图文布局比例（如 `1:2`、`2:1`），并能一键读取思源超级块的拖拽列宽。
- **丝滑页面转场**：向左平滑滑入、优雅淡入淡出等现代转场动效，让演示翻页自然流畅。

#### 2. `v-click` 渐进显隐与入场微动效，牢牢抓住听众注意力
- **渐进弹出 (`v-click`)**：支持对列表项、正文段落甚至多栏内的独立子组件单独配置逐步呈现步长。随着演讲节奏敲击翻页键逐项浮现，有效避免听众提前阅读后续文字，牢牢牵引全场注意力。
- **灵动微动效**：内置上浮 (`slide-up`)、淡入 (`fade-in`)、缩放 (`zoom-in`) 与微弹跳 (`bounce`) 等多种入场动效，为要点展示增添精致感。
- **Shiki 代码逐行聚光**：针对技术分享中的代码块，预设聚光行区间（如 `1-3|5|7-10`），翻页时光束在关键代码之间推移切换，复杂逻辑一目了然。

#### 3. 动态蒙版动画，AI 生图与数据推演的绝佳搭档
支持为幻灯片添加动态蒙版遮罩：
- 提供**从左至右**、**从上至下**及**时钟走时（四步环形展露）**等多种动画方式。
- 非常适合搭配 AI 生成的宽幅概念图、全景流程图或数据对比图表。随着讲解深入分段逐层揭开面纱，呈现层层递进、引人入胜的视觉悬念与叙事推演。

#### 4. 笔记样式智能映射为演示排版，所见即所得
- 笔记中的各级标题大小、文本强调颜色、思源调色板高亮以及横向超级块布局，全部自动映射为大屏演示排版。
- 开启「全局标题大小规范化」即可自动平衡整篇文档各页标题的视觉重心；配合「全局与单页间距预设（紧凑/标准/宽松）」，笔记怎么写，演示就怎么出彩，彻底消除手工调字号、调间距的烦恼。

### 三、沉浸式演示效果，让观众始终不出戏

#### 1. 内置轻量 Web 沙箱，访问网页、操作 Demo 不跳出演示模式
在进行技术演示、产品发布或方案汇报时，往往需要展示在线文档或交互原型：
- 点击幻灯片中的外部网页链接，右侧即刻滑出**内置微型浏览器速览抽屉**，支持 50%~250% 缩放自由调节、一键切换**桌面/手机视图**模拟移动端响应式页面，并自动继承思源的网络代理配置。
- 演示中引用的**本地 HTML 交互文件**或**思源文档**可直接原位渲染展示。
- 测试演示完成后，按下 `Esc` 键抽屉瞬间收起，直接回到当前幻灯片继续讲解，全程无需频繁切换窗口、不暴露系统桌面，观众注意力始终凝聚在演示本身。

#### 2. 点击图片无损放大，细节一览无余
- 放映中点击任意图片即可进入全屏高清灯箱。
- 支持使用鼠标滚轮以光标所在位置为中心进行 **1~5 倍自由平滑缩放**，按住鼠标拖拽平移查看超大架构图或数据报表的微小细节，双击快速复位。再复杂的工程图表与报表截图，台下观众也能看得清清楚楚。

#### 3. 全局缩略图浏览与极速跳页，从容应对现场互动
- **全景缩略图画廊 (`O` 键)**：演讲互动或答辩被问到前面内容时，无需一页页按翻页键倒退。按下快捷键 `O` 即可一键呼出全局缩略图总览墙，网格化全景直观展示所有页面的真实排版与内容，点击任意卡片即可瞬间精准直达。
- **数字键直达跳页**：放映中直接键入目标页码（如输入 `8`），屏幕右下角浮现半透明数字角标，按下回车键立刻直达目标页。
- **鼠标滚轮翻页**：放映与预览均支持鼠标滚轮自然滑动翻页，并内置智能冷却防抖与局部滚动优先机制，操控丝滑自然。

### 四、专业的演讲者双屏视图，无惧忘词

#### 1. 内嵌演讲者备注作为提词卡，一个文档包含所有演示信息
无需单独打印纸质讲稿，也不用在手机上备忘小抄。每页幻灯片下方均提供专属的提词卡备注区域，输入的内容仅在演讲者屏幕呈现。演示、备注、知识库内容在思源同一篇文档中融为一体，真正做到演示资产集中沉淀。

#### 2. AI 智能分页与提词生成，长篇调研笔记一键成稿
- **AI 智能分页**：长达数万字的行业调研、深度读书笔记或总结报告，只需点击面板中的「🤖 AI 智能分页」，AI 即可根据文章层级逻辑自动在最合适的位置插入分页线并推荐专业版式。
- **AI 智能提词**：点击「🤖 AI 提词生成」，AI 自动提炼当前页的核心论点与逻辑衔接，生成通俗易懂的口播引导词。
- 5 分钟之内，将一篇沉睡在知识库中的静态长文快速转化为高水平的演讲稿。

#### 3. 专业演讲者双屏视图，告别忘词与时间失控
按下快捷键 `P` 即可启动双屏演讲者控制台，提供比肩专业发布会的控场体验：
- **独立大屏窗口一键弹出**：支持将放映画面弹出为标准的 16:9 独立窗口，外接投影仪或在腾讯会议、Zoom、钉钉中单独共享该窗口；控制台则留在自己的笔记本主屏上。
- **双显时钟与用时计时**：主屏顶部集成系统真实时钟与演讲用时计时胶囊，有效防止超时，演讲节奏一目了然。
- **当前与下一页等比缩略图**：主屏不仅显示当前放映画面，更提供下一页预告，以及当前动画步进提示和半透明“剧透预览”，让演讲者永远对下一拍内容心中有数。
- **大字号口播提词卡**：提词文本支持 `A-`/`A+` 实时调整字号，即便站立在讲台上也能轻松扫读，彻底告别忘词尴尬，现场游刃有余。

## 📦 全渠道离线导出与分享

演示不仅限于在思源笔记内播放，插件提供全方位的脱机交付与分发方案：

- **单文件独立离线 HTML**：将演示运行时、排版样式、幻灯片数据以及引用的图片资源全部封装内联为一个独立的 `.html` 文件。将该文件发送给他人，对方在任意未安装思源笔记和断网的电脑上双击即可全屏放映，且完整保留滚轮翻页、跳页、总览画廊与图片灯箱功能。
- **高清横版 PDF 讲义**：支持直接导出 16:9 / 4:3 / A4 横版高分辨率 PDF 文件，适合课件分发、答辩归档与离线打印。
- **幻灯片导出为高清图片**：支持将整套幻灯片逐页导出为 PNG 图片压缩包，或仅导出当前页单张图片，方便快速发送到即时通讯群组或社交平台。

## 🎨 常用版式速查

在笔记中输入原生分割线 `---` 即可开启新幻灯片。光标停在分割线上，右侧面板即可直观点选版式：

| 版式 (`layout`) | 适用场景 | 呈现效果 |
| :--- | :--- | :--- |
| `cover` | 演示封面 | 居中大标题、副标题与演讲者信息 |
| `default` | 标准正文 | 顶部标题，下方富文本内容与列表 |
| `two-cols` | 双栏对比 / 图文排版 | 左右双列自适应布局，支持自定义比例 |
| `cols-header` | 结构化并列论点 | 顶部通栏标题，下方自适应 2~6 栏，支持栏内组件级逐步呈现 |
| `clover` | 四象限要点 | 4 项超级块 2×2 田字型卡片布局 |
| `image-right` / `image-left` | 图文排版 | 一侧全屏背景图，一侧内容，配图角色自动智能推断 |
| `fact` | 核心结论 / 大字报 | 超大字号居中呈现关键数字或核心结论金句 |
| `intro` | 章节过渡 / 个人简介 | 突出标题与引言，适合演讲转场 |
| `center` | 居中内容 | 全内容水平垂直居中展示 |
| `quote` | 名言引用 | 突出名言金句与出处说明 |

## ❓ 常见问题 (FAQ)

<details>
<summary><b>Q1: 使用本插件必须在电脑上安装 Node.js 或配置环境吗？</b></summary>
<b>完全不需要！</b> 插件原生内置了轻量 Web 沙箱渲染引擎，在思源笔记集市中一键下载启用即刻可用，0 外部依赖，离线也能秒级开启演示。
</details>

<details>
<summary><b>Q2: 插件会在我的笔记正文里添加乱七八糟的标记或代码吗？</b></summary>
<b>绝对不会。</b> 「正文零污染」是本插件的核心设计底线。所有动画、版式、演讲提词均写入思源原生的 IAL 块属性字典（<code>custom-slides-*</code>）和分割线中。您的 Markdown 正文保持 100% 纯净，导出或同步到手机端阅读时绝无任何乱码或宏标记。
</details>

<details>
<summary><b>Q3: 导出的单文件 HTML 可以在没装思源笔记和没有网络的电脑上播放吗？</b></summary>
<b>可以。</b> 导出的单文件 HTML 将所有运行时脚本、排版样式、幻灯片数据及引用的本地图片资源完全内联打包。只需将该单文件通过邮件或微信发送给他人，对方双击用任何现代浏览器（Chrome、Edge、Safari 等）打开即可离线全屏放映。
</details>

<details>
<summary><b>Q4: 演讲者双屏视图在腾讯会议或 Zoom 等远程会议中如何使用？</b></summary>
在放映时按下键盘 <code>P</code> 键打开演讲者控制台，点击顶部「独立放映窗口」按钮，放映画面将弹出为一个标准的独立 16:9 窗口。在腾讯会议/Zoom/钉钉等会议软件中选择<b>“仅共享该独立放映窗口”</b>给与会人员，而演讲者控制台（包含计时器、口播提词卡与剧透预告）留在您的主屏幕上供您从容参考，参会观众看不到您的私有提词。
</details>

<details>
<summary><b>Q5: 如果我不常用某些高级功能，可以精简界面吗？</b></summary>
<b>可以。</b> 插件在思源设置中提供了细致的功能开关，您可以按需隐藏不常用的导出通道、Pro 模式或 AI 入口，右侧面板与工具栏将自动精简，让操作界面更加聚焦与轻巧。
</details>
