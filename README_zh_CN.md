# 思源笔记 Slidev 演示插件 (SiYuan Slidev)

[English](./README.md)

> **“让笔记即是演示，让演讲回归内容；零污染元数据沉淀，现代前端级酷炫视觉呈现。”**

`siyuan-slidev` 是专为思源笔记（SiYuan Note）打造的现代化一体化演示插件。深度依托思源底层的**块级细粒度架构**与 **IAL 自定义属性系统**，将现代前端最先进的组件化演示框架 **Slidev** 引入思源生态，彻底解决传统演示工具“排版丑陋、正文宏代码严重污染、打字卡顿”的痛点。

---

## 核心特性

- 🎯 **正文零污染 (Zero-Pollution Metadata)**：所有版式（Layout）、转场动效（Transition）、背景、演讲备忘录（Notes）均保存在水平分割线（`---`）或块属性 `custom-slidev-*` 中，Markdown 笔记纯净整洁。
- ⚡ **双模渲染引擎 (Dual presentation engines)**：
  - **内置轻量 Web 沙箱**：零外部依赖，免装 Node/CLI 环境，纯前端毫秒级加载。
  - **Pro 极客模式**：支持直接桥接本地运行的 `slidev` CLI 端口（默认 3030），享受完整 npm/Vue SFC 生态。
- 🔄 **双向毫秒级联动 (Bi-directional Sync)**：
  - 编辑器光标聚焦到某段落，右侧幻灯片毫秒级翻页并光晕定位；
  - 点击幻灯片沙箱中的任意元素，左侧编辑器自动平滑滚动并对齐对应笔记块。
- 🪄 **专精可视化微交互**：
  - **水平分割线悬浮气泡**：点击 `---` 即可弹出九宫格版式选择器、转场动效预览器、背景图与讲师提词输入框；
  - **元素级动效条**：选中文本或点击块标，一键配置 `v-click` 渐进显隐、分栏插槽与代码逐行聚光。
- 🎤 **专业双屏演讲者视图 (Presenter Mode)**：
  - 独立双屏投影视窗，内置演讲计时器、当前大屏画面、下一页预告与大字号口播提词卡。
  - 主屏与演讲屏基于广播通道双向毫秒级同步。
- 📦 **全渠道离线导出**：
  - **单文件独立离线 HTML**：将脚本、样式、数据与图片一键打包，脱机离线亦可在任意浏览器放映；
  - **高保真 PDF 讲义导出**：支持调用系统打印直接输出 16:9 横版高分辨率讲义。
- 🤝 **与「属性管家」深度协同**：
  - 预设 Slidev 属性模板字典，一键套用；
  - 支持在属性管家统计面板中全库盘点演示资产，一键批量重构转场动效。
- 🤖 **AI 智能赋能**：
  - **AI 智能分页**：根据长文层级与容量，智能建议并插入分页分割线；
  - **智能动效注入**：识别列表项逻辑，自动分配渐进出现序列；
  - **提词卡提炼**：自动从幻灯片块提取大纲，生成讲师口播提示。

## 快速上手

1. 在思源笔记中打开任意文档。
2. 点击顶栏右上角 **「Slidev 演示」** 图标（或快捷键 `Alt+P` / `⌥P`），右侧 Dock 栏即刻展开实时预览。
3. **分页与排版**：在文档中输入原生水平分割线 `---`，即代表新开启一页幻灯片。
4. **可视化配置**：点击该分割线即可弹出气泡面板，点选封面（cover）、双栏（two-cols）、大字报（fact）等版式；
5. **快捷键放映**：
   - `→` / `Space` / `PageDown`：下一动画动作 / 下一页；
   - `←` / `PageUp`：上一动作 / 上一页；
   - `F`：切换全屏演示；
   - `P`：呼出双屏演讲者控制台。

## 块属性协议字典 (Block Attributes)

| 作用级别 | 属性名称 (`Attribute Key`) | 取值示例 | 说明 |
| :--- | :--- | :--- | :--- |
| **文档全局** | `custom-slidev-theme` | `"default"` \| `"seriph"` | 全局演示主题 |
| **文档全局** | `custom-slidev-aspect-ratio`| `"16/9"` \| `"4/3"` | 画面宽高比例 |
| **页面级** | `custom-slidev-slide` | `"true"` | 显式标记开启新幻灯片 |
| **页面级** | `custom-slidev-layout` | `"cover"` \| `"two-cols"` | 幻灯片版式 |
| **页面级** | `custom-slidev-transition` | `"slide-left"` \| `"fade"` | 页面切换转场动效 |
| **页面级** | `custom-slidev-notes` | 文本字符串 | 演讲者私有备忘录 |
| **元素级** | `custom-slidev-click` | `"+1"` \| `"1"` \| `"hide"` | 逐步出现步进动画 (`v-click`) |
| **元素级** | `custom-slidev-shiki-lines`| `"1-3\|5\|all"` | 代码块逐行聚光高亮 |
| **元素级** | `custom-slidev-slot` | `"left"` \| `"right"` | 双栏分栏插槽归属 |
